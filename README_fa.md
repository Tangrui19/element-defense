# دفاع عنصری · Element Defense

یک بازی دفاع برجی HTML5 با Canvas و JavaScript خالص؛ بدون فریم‌ورک، CDN یا مرحله Build.

## امکانات

- شش نوع برج با نقش‌های متفاوت: تیر سریع، انفجار منطقه‌ای، کندکردن، زنجیره برق، تک‌هدف دوربرد و آسیب تدریجی.
- شش نوع دشمن: معمولی، سریع، زره‌پوش، گروهی، پرنده و Boss.
- دوازده موج داده‌محور با ترکیب‌های متفاوت.
- زره، کندی، سم، محدودیت هدف‌گیری پرنده‌ها و اولویت هدف قابل تنظیم.
- پیش‌نمایش موج، شمارش معکوس، پاداش شروع زودتر و پاداش پاک‌سازی موج.
- وضعیت‌های مشخص: آماده‌سازی، نبرد، توقف، شکست و پیروزی.
- شبیه‌سازی با گام زمانی ثابت و رابط واکنش‌گرا.

## اجرا

```bash
node server.mjs
```

سپس آدرس زیر را باز کنید:

```text
http://localhost:8000
```

## کنترل‌ها

- انتخاب کارت برج و کلیک روی خانه خالی برای ساخت.
- کلیک روی برج ساخته‌شده برای مشاهده جزئیات و تغییر اولویت هدف.
- کلیدهای `1` تا `6` برای انتخاب برج.
- کلید `P` برای توقف یا ادامه.
- کلید `Esc` یا کلیک راست برای لغو انتخاب.
