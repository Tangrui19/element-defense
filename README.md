# 元素塔防 · Element Defense

一个无依赖、无构建步骤的 HTML5 Canvas 塔防游戏。使用原生 HTML、CSS 与 ES Modules 实现。

## 当前内容

- 6 种定位明确的炮塔：单体速射、范围爆破、减速控制、连锁闪电、远程重击、持续毒伤。
- 6 类敌人：突击兵、疾行者、重甲兵、噬群虫、飞行单位与 Boss。
- 12 个数据驱动波次，包含混编、虫潮、空袭与多 Boss 终局。
- 护甲减伤、减速、持续伤害、飞行单位与炮塔对空限制。
- 每座炮塔可切换目标优先级：最前方、最强、最近、最后方。
- 波次预览、自动开波倒计时、提前开波奖励与清波奖励。
- 明确游戏状态：布防、交战中、暂停、失败、胜利。
- 固定时间步模拟，不依赖显示器刷新率。
- 响应式界面、Canvas 粒子/命中特效、范围预览和移动端布局。

## 运行

### 最简单：双击即玩

Windows 下直接双击：

```text
元素塔防-双击即玩.html
```

或双击 `启动游戏.bat`。单文件版本已经把 CSS 和全部游戏代码内联，不需要 Node、服务器或联网。

> 不要直接把 ZIP 中的 `index.html` 单独拖进浏览器，否则浏览器拿不到 CSS、Canvas 脚本等相邻文件。

### 开发模式

源码版使用 ES Modules，需要通过静态服务器打开：

```bash
node server.mjs
```

然后访问：

```text
http://localhost:8000
```

也可以使用任意静态服务器托管项目目录。

修改源码后，重新生成单文件版本：

```bash
node tools/build-standalone.mjs
```

## 操作

- 点击炮塔卡，然后点击空白格建造。
- 点击已经建成的炮塔，可查看属性和切换目标优先级。
- `1` 到 `6`：快速选择炮塔。
- `P`：暂停/继续。
- `Esc` 或右键：取消当前选择。
- 在布防阶段提前开波会按剩余时间获得额外资金。

## 测试

```bash
node tests/run.mjs
```

测试覆盖路径模型、战斗与状态效果、波次配置、防重复开波、暂停、建造规则、渲染器烟雾测试、DOM 契约和 UI 初始化。

## 项目结构

```text
src/
  config.js        地图、炮塔、敌人和波次配置
  path.js          地面路径与飞行路径模型
  entities.js      敌人、炮塔和弹丸
  combat.js        目标选择与连锁攻击
  wave-manager.js  波次生成与进度
  game.js          游戏状态、经济和固定时间步逻辑
  renderer.js      Canvas 渲染与特效
  ui.js            HUD、建造菜单、敌情雷达和选择面板
  main.js          浏览器入口
tests/             无依赖逻辑与 DOM 契约测试
server.mjs         零依赖静态服务器
```

## 技术约束

- Vanilla JavaScript (ES2020+)
- HTML5 Canvas
- CSS3
- 无框架、无 CDN、无外部资源请求
- 可通过 GitHub Pages 静态部署
